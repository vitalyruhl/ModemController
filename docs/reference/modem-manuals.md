# Modem manual sources

Manufacturer manuals are obtained separately from their publishers. They are
not included in the public source tree or portable release. Existing local
copies can remain available for personal reference.

The official entry points below were checked on 2026-09-19. They are support
or download portals, not verified direct downloads of these legacy editions.
Availability and account requirements are controlled by the publisher.

| Reference document | Publisher / product | Official source and access notes |
| --- | --- | --- |
| ELSA MicroLink Office AT command reference (`elsa-microlink-at-commands.pdf`) | ELSA MicroLink Office | [devolo support](https://www.devolo.com/en/support/direct-contact) is a current MicroLink-related vendor contact. Ask specifically about the legacy ELSA Office document; availability and support for that ELSA model are unconfirmed. Use the original product media if available. |
| Developer's Guide: M2M Technology, Getting Started, version 1.0, August 2012 (`m2mdev_M2M_Developer_Guide_4551.pdf`) | Deutsche Telekom; general M2M guide | [Deutsche Telekom IoT contact](https://iot.telekom.com/en/contact). Request this title and edition; a direct official download was not verified. This is not an MC88-specific AT specification. |
| TC35 Terminal Benutzerhandbuch (`tc35-german.pdf`) | Siemens TC35 Terminal | [Telit Cinterion Download Zone](https://www.telit.com/support-tools/download-zone/). Request legacy Siemens/Cinterion TC35 documentation; registration and approval may be required. |
| TC35i Terminal Hardware Interface Description, version 03.01a, `TC35i_T_HD_v03.01an` (`tc35i_t_hd_v0301n.pdf`) | Cinterion TC35i Terminal | [Telit Cinterion Download Zone](https://www.telit.com/support-tools/download-zone/). Request this exact product and document revision. |
| TC35/TC37/TC35T AT Command Set, version 04.00 (`tc3x_atc_01_v0400.pdf`) | Siemens cellular engines | [Telit Cinterion Download Zone](https://www.telit.com/support-tools/download-zone/). Request the applicable legacy command reference and confirm the modem firmware revision. |

Use the command reference for the exact modem and firmware. A historical
example in a manual is not evidence that a command is supported by another
device, and obtaining a document does not authorize executing its examples.
